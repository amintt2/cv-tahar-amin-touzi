01 Produit SaaS · depuis mai 2026

Mailbase

  • En ligne
  • Fondateur

Agent de prospection par e-mail bâti sur le registre SIRENE : il trouve les entreprises, vérifie les adresses, rédige des e-mails personnalisés par IA et trie les réponses par intention.

  • Envoi multi-tenant (Amazon SES, useSend) avec coupe-circuit sur les rebonds et plaintes, conçu après un vrai incident d'abus.
  • Assistant agentique intégré (Vercel AI SDK, multi-fournisseurs) et serveur MCP avec OAuth : Claude, Cursor ou Codex agissent sur les données du workspace. Distribué en plugin Codex.
  • Facturation Stripe, quotas par offre, interface bilingue FR/EN, boîte de réception triée par intention, workflows, tests A/B.
  • API publique d'envoi réutilisée comme infrastructure e-mail par 4 de mes autres projets.
  • 473 commits, 145 fichiers de tests (unitaires + navigateur Playwright), 106 migrations SQL, CI.
  • Next.js 16
  • PostgreSQL
  • Auth.js
  • Amazon SES
  • Stripe
  • Vercel AI SDK

02 App iOS · sortie le 7 sept. 2026

Scrollworthy

  • App Store
  • Web en ligne

Une app iOS qui bloque les réseaux sociaux et convertit un effort réel vérifié (sport, travail, pas) en minutes de scroll.

  • API Screen Time : FamilyControls, ManagedSettings, extensions DeviceActivity et Shield qui partagent leur état via un App Group.
  • Objectifs faits de « vérificateurs » : minuteur avec photos surprises, géorepérage, HealthKit, NFC/QR, et un service anti-triche.
  • Mode duo et modèles communautaires en pair-à-pair (Holepunch Bare Kit + hyperswarm) embarqués dans iOS.
  • Paywall RevenueCat + paiement web, programme d'affiliation pour créateurs (liens, webhooks, commissions, app « Creators »).
  • Autour de l'app : tableau de bord web avec passkeys, et une app macOS notarisée qui monte des vidéos courtes avec Remotion.
  • SwiftUI
  • SwiftData

03 Jeu vidéo & 3D · sept. 2026

Brumeval Online

  • En ligne
  • Open source

Un MMORPG multijoueur jouable dans le navigateur, dont tous les modèles 3D, animations et icônes sont générés par code avec Blender.

  • Serveur Node.js autoritatif (WebSocket, deltas, grille spatiale) avec anti-triche vitesse, téléportation et murs.
  • Client Three.js : cycle jour/nuit synchronisé par le serveur, ombres en cascade, HDR, terrain PBR, herbe et eau.
  • Pipeline Blender 5 sans interface : 77 scripts Python génèrent chaque asset (matériaux nodaux, baking GPU, LOD). Aucun asset téléchargé.
  • Combat exigeant, 3 classes, boss en 3 phases, arbre de 65 talents piloté par les données, comptes avec passkeys.
  • 109 commits en 4 jours, launcher Electron (Windows, macOS, Linux) et PWA.
  • Three.js
  • Node.js
  • WebSocket
  • Blender · Python

04 Produit SaaS · août 2026

LaRelance

  • En ligne
  • Premier client

Campagnes SMS pour les commerces de proximité : le commerçant importe son fichier client, écrit sa promo, voit le coût exact et envoie. La conformité française est gérée par la plateforme.

  • Premier client : une pizzeria, environ 400 contacts.
  • Import de fichiers de caisse désordonnés avec détection des colonnes assistée par IA ; rédaction IA en 3 angles, avec comptage exact des segments GSM-7/UCS-2 renvoyé au modèle.
  • Données personnelles masquées caractère par caractère avant tout appel au LLM, avec une garde finale.
  • STOP, plages horaires légales avec report automatique, coupe-circuit au-delà de 5 % de désinscriptions.
  • File d'envoi verrouillée en base : un seul expéditeur par campagne, reprise possible, jamais de double envoi.
  • Next.js 16
  • PostgreSQL
  • Drizzle
  • better-auth
  • Stripe

06 IA & outils dev · sept. 2026

coolify-mcp

  • Open source · MIT
  • Site en ligne

Un serveur MCP qui permet à un agent IA de piloter en toute sécurité une instance Coolify auto-hébergée.

  • 18 outils : découverte des apps, services, bases et serveurs, variables d'environnement, déploiements, logs.
  • Secrets masqués par défaut (les révéler demande un drapeau côté outil et côté serveur), dry-run des changements, mode lecture seule.
  • Contourne un comportement de l'API Coolify qui réinitialise silencieusement des options ; jetons masqués dans les erreurs.
  • Tests, CI, site avec générateur de configuration. Né de l'exploitation de mes ~10 apps en production.
  • TypeScript
  • Node 20
  • MCP SDK
  • Coolify API
  • GitHub Actions

07 Produit SaaS · août 2026

Ardoise

  • En cours

Logiciel de caisse pour pizzerias et restauration rapide, conforme à la loi anti-fraude TVA, où la caisse est elle-même le serveur.

  • Journal fiscal (CGI art. 286-I-3° bis) : écriture seule imposée par triggers SQLite, séquence sans trou, chaînage SHA-256, signature Ed25519 par caisse.
  • Hors-ligne d'abord, cloud en miroir, imprimantes ESC/POS et écran cuisine en réseau local.
  • Deux auto-audits adverses : 13 failles trouvées, dont 3 critiques, corrigées. 54 fichiers de tests.
  • Bun
  • Expo · RN Web
  • Next.js
  • SQLite · Drizzle

08 App iOS & IA · août 2026

Dossier

  • Prototype

Un coffre-fort de papiers administratifs sur iPhone : l'IA embarquée lit, classe et surveille les échéances, sans que rien ne quitte l'appareil.

  • Apple Foundation Models (LLM embarqué) avec un harnais d'agent : modes de permission, flux d'événements, annulation complète.
  • Dates candidates déterministes et vérificateur indépendant (MRZ du passeport) : aucun rappel ne repose sur une date inventée.
  • Un mini-langage de requête (parseur descendant récursif) partagé par la recherche et les règles de classement. Chiffrement AES-GCM + Keychain.
